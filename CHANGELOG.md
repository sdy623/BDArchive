# Changelog

## 0.3.0 — 2026-10-14

First public release. Version numbering starts at 0.3.0; previous local build and engine phase numbers do not indicate public releases. Archive schemas and existing disc IDs are unchanged.

- Native Windows WebView2 desktop, embedded Python, original application icon, explicit CJK/monospace font fallbacks.
- English / Simplified Chinese workbench and PowerShell/BAT archive engine.
- Photo RAW, game-recording and independent DwarFS backup-shard workflows.
- Read-only existing JSON/SQLite library connection; searchable, filtered, paginated disc/content index.
- Actual next P/G/B/M identifiers and global index, custom drafts and guarded counter writes.
- Per-disc explicit physical-burn confirmation, default preview, logs and cooperative cancellation.

Limitations: unsigned EXE; Windows x64 only; WebView2 and PowerShell required; archive CLI tools are configured separately. Dark theme only in this release. Advanced cleanup is CLI-only and React restore exposes preview. Synthetic tests are not physical-disc certification.
